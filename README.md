# 《符文王座：暗影觉醒》
**Rune Throne: Shadow Awakening** — 西方幻想 · 文字RPG（自由探索式网页游戏）

---

## 一、游戏概述

- **类型**：**文字RPG** —— 自由探索 + 文字叙述冒险 + 指令式回合战斗
- **平台**：纯前端网页（HTML/CSS/JS + 手绘 SVG 插画），双击 `index.html` 即可游玩，零依赖、可离线
- **核心体验**：你扮演一名流浪剑士，在艾尔多兰王国的地图上**自由行走**——每一步移动、每一场遭遇、每一次交谈，都以文字实时写入**冒险日志**；随时打开**行囊 / 技能栏 / 角色面板**
- **收录内容**：序章「风雨之夜」+ 第一部「晨曦之印」+ 第二部「星辰之印」+ 第三部「海洋之印 · 潮歌湾」+ 第四部「丰收之印 · 金穗平原」，共 **53 个地点**、17 种敌人、**5 条支线**、对质线索与谜题旁路多套，**6 种章节收尾**可收集；第五、六部与终部规划中
- **时长**：单周目约 130~180 分钟（含支线与探索），支持多周目与结局收集

## 二、玩法（与旧版分支剧情的区别）

| 旧版（章节卡片式） | 现版（文字RPG） |
|---|---|
| 一屏一段剧情 + 选项卡片推进 | **世界地图**：地点之间用方位按钮自由来去（↑北 ↓南 ←西 →东 / 上楼下楼） |
| 每个选择都是一次性分支 | 地点可反复探索：NPC 交谈、调查、商店、休息随时可用 |
| 状态只显示在侧栏 | 顶栏常驻 **🎒背包 / ⚔技能 / 👤角色 / 🗺地图** 按钮（快捷键 B / K / C / M），随时打开 |
| 战斗内嵌在剧情页 | **遭遇战 v2**：战斗写入同一份冒险日志，敌方小队条与同伴状态条常驻指令栏上方；每回合先看敌人**意图**，再决定出手/防御/用药 |
| — | **同伴与成长**：同伴是独立战斗单位（态势 AI 协同作战）；升级时**自选强化**，构建自己的流派 |

### 指令栏
- **去路（方位按钮）**：显示当前地点所有可走的出口；有条件的出口会 🔒 灰显并提示原因
- **此处可做**：环顾四周、与 NPC 交谈、调查、休息、剧情动作（随进度出现）
- 剧情事件进行时，指令栏会临时切换为事件选项（谜题、战斗、抉择）

### 探索系统
- **世界地图总览**：顶栏 🗺 地图（快捷键 **M**）随时打开「艾尔多兰行记图」——按章节/小节列出全部地点，走过的逐格点亮，没去过的以雾（？？？）遮蔽，并统计探索度
- **旅途随机事件**：在野外地点之间赶路时，可能遇上云游诗人、逃难的农户、赶路的商队、遗落的行囊、低飞的鸦群；第二部之后还会遇见唱潮谣的渔人，第三部之后是怀里揣着麦穗的稻草人——小额得失与见闻，有独立冷却，不会连着刷
- **隐藏角落**：古井、地窖、湖心洲、地宫、废矿、沉船湾、潮汐洞窟、老磨坊……每个章节都藏着与主线若即若离的地点：有的给装备（咏祭礼剑 / 鲸骨长枪 / 潮珠），有的给线索与谜底（古祠碑文 → 圣殿大门古谚；磨盘刻痕 → 丰年祭坛农谚），有的只是给世界添一层厚度
- **支线与传闻联动**：下城区的施舍会印证渡鸦的传闻；卫戍营房的情报与溃兵营地的调令指向同一只手；老船长的潮汐口诀与守塔人的荧藻同指一扇海路——多走多问，戏就更足

### RPG 系统（战斗与角色 v2）
- **属性**：生命 HP、斗气✦ SP（主角每回合 +2，同伴 +1）、金币、声望、经验/等级、隐藏**侵蚀值**
- **装备**：三个装备位——**武器**（攻击加成，只加成物理技）、**防具**（受伤减免）、**饰品**（生命上限/斗气上限/会心率等）。行囊中点击「装备」穿上，角色面板可「卸下」
- **同伴系统**：艾莉娅/索恩/**卡雅**入队后是**独立战斗单位**，各有生命与斗气（随等级成长），按「态势」自动作战——**均衡**（残血时治疗/自保）/ **强攻**（全力输出）/ **守护**（优先格挡），战斗指令栏一键切换；生命归零会**昏厥**：可用药剂救醒，战后自动缓复两成，休息点全队恢复
- **升级自选强化**：每升 1 级四选一——生命+6 / 斗气+2 / 攻击+1 / 同袍协力（同伴上限成长）；主角 Lv4 解锁【回旋斩】（全体攻击）
- **技能表**：主角 ⚔挥剑 · 💥强袭斩 · 🌀回旋斩(Lv4) · 📢破胆吼（全体敌人伤害-2） · ☀️符文之刃 · 🌊潮汐之刃（海洋之印解锁） · 🌾穗浪千重（丰收之印解锁，全体）；艾莉娅 ✨星火弹 · 🛡星辉庇护（全队减伤+驱毒） · 💚治愈星雨；索恩 🪓旋风斧 · 🛡铁壁 · 🔥战吼；卡雅 🔱迅叉连刺 · 🐋鲸涛斩 · 🌀潮环回斩（同伴技能由态势 AI 自动施展，敌众重击前会主动格挡）
- **战斗 v2**：每回合开头宣告敌人**意图**（⚠ 重击/淬毒/凝盾/锁链/雾遁/汲命……），可趁机**防御**（受伤大减+斗气+1）或调整目标；多敌人遭遇需选择攻击目标；潜行救援、飞扶壁攀爬、海滩合围等路线可获**先手**（首回合敌人措手不及）
- **敌人机制**：重击技（意图预告，可防）、淬毒、黑盾（先破盾再伤血）、星穹锁链（概率眩晕）、雾遁（物理无效，魔法仍可命中）、**汲命**（吸血回复）、敌众士气、BOSS 半血狂怒、护甲（物理减伤，魔法无视）、物理暴击；敌人也会**转火同伴**（同伴自带基础护甲）
- **侵蚀机制**：每点侵蚀使攻击 +1（深渊之力），但每场战斗开始时失去等量生命——力量与代价并存，且决定每一部的收尾走向
- **物品**：生命药水（回复10）/ 大生命药水（回复25），行囊与战斗中均可使用，会**自动救醒昏厥的同伴**；星光护符（濒死自动碎裂）；符文与关键道具（行囊中查看）
- **游荡遭遇**：雾林小径、山麓岔路、城西小巷、礁滩、田垄等地行走时可能遭遇敌人（有冷却，不会连着刷）；荒野路段则有更轻的**旅途事件**（见「探索系统」）
- **休息点**：旅店客房、黄昏营地、海底神殿咏泉（免费）；采药人小屋（3金币）；驿镇客栈（5金币）；穗安村（5金币）；渔家客栈（6金币）——**全队**生命斗气全满

### 章节收尾（结局收集）

### 小节与线索系统
- 每个地点带**小节标签**，章节/小节切换时在冒险日志中打印分隔行，顶栏章节显示「第四部 · 丰收之印 · 小节三 · 丰年祭」
- **对质线索**：溃兵营地的调令线索（`deserterClue`）与藏书阁的先王家徽记载（`libClue`）会让「当庭揭发」一场戏多出整整两段台词——线索越多，揭发越有力（奖励相同，剧情演出不同）。卫戍营房与下城区也能补上旁证（营房情报可独立获得调令线索）
- **谜题提示的旁路**：圣殿大门的古谚，除了渡鸦的传闻与大殿经卷架，还能从**林中古祠的碑文**自己悟出来；丰年祭坛的五谷次序，蓉婆婆的农谚是正解，老磨坊被凿断的刻痕是旁证
- **潮汐三件套**：老船长的口诀（或码头木牌）→ 守塔人的荧藻 → 大退潮之夜的海路——三步环环相扣，跳步会被🔒挡回
- **剧情道具**：影蚀手记（圣殿回廊）、机关图志残页（藏书阁，星塔谜题免伤直解）、影蚀潮令（海底神殿，影蚀的下一步）、祭典谷种（老磨坊）、深渊螺壳（祭坛抉择，收下即染侵蚀）
- **探索装备**：咏祭礼剑（武器 攻击+2）、雾泽明珠（饰品 生命上限+3）、鲸骨长枪（武器 攻击+3 · 沉船湾沉箱）、潮珠（饰品 斗气上限+4 · 潮汐洞窟）、深海珍珠（饰品 生命上限+5 · 荧藻报酬）——不进商店，只留给肯绕路的人

## 五、文件结构与运行

```
文字游戏/
├── index.html          # 页面骨架 + 世界设定集弹窗
├── style.css           # 幻想风格视觉主题
├── js/
│   ├── world.js        # 世界数据：地点/事件/敌人/物品/技能/任务/商店
│   ├── engine.js       # 引擎：日志/移动/面板/战斗/商店/支线/存档/收集
│   ├── story.js        # （旧版章节脚本，已停用，仅留档）
│   └── story_future.js # （旧版预留剧情，已停用，仅留档）
├── tests/
│   ├── smoke.js        # 无浏览器冒烟测试（DOM 桩加载器）
│   ├── driver.js       # 测试驱动：跑通全部主线+支线+全地点，113 项断言
│   ├── balance.js      # 战斗平衡模拟：关键战斗 ×400 场自动对局
│   └── validate_world.js # 世界一致性校验：出口/方位/敌人/物品引用
├── assets/
│   ├── scenes/*.svg    # 场景插画（作为日志背景氛围图）
│   └── chars/*.svg     # 角色立绘
└── README.md           # 本设计文档
```

**运行**：直接双击 `index.html`；或在目录下执行 `python -m http.server 8000` 后访问 `http://localhost:8000`。
**测试**：`node tests/smoke.js`（无需浏览器，自动跑通序章至第四部的全部主线、支线与新地点流程，含战斗 v2 与章节收尾断言）；`node tests/validate_world.js`（世界一致性：出口/方位/敌人/物品引用完整）；`node tests/balance.js`（战斗平衡模拟：各章节关键战斗 ×400 场自动对局，输出胜率/耗药/收官血量，调数值后请重跑）。

> 小技巧：
> - 访问 `index.html?fast=1` 开启速读模式（跳过打字机与演出延迟）。
> - 快捷键：**B** 行囊 · **K** 技能 · **C** 角色 · **M** 地图 · **Esc** 关闭弹窗 · **空格/回车** 快进文本。
