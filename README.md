# 《符文王座：暗影觉醒》
**Rune Throne: Shadow Awakening** — 西方幻想 · 文字RPG（自由探索式网页游戏）

---

## 一、游戏概述

- **类型**：**文字RPG** —— 自由探索 + 文字叙述冒险 + 指令式回合战斗
- **平台**：纯前端网页（HTML/CSS/JS + 手绘 SVG 插画），双击 `index.html` 即可游玩，零依赖、可离线
- **核心体验**：你扮演一名流浪剑士，在艾尔多兰王国的地图上**自由行走**——每一步移动、每一场遭遇、每一次交谈，都以文字实时写入**冒险日志**；随时打开**行囊 / 技能栏 / 角色面板**
- **收录内容**：序章「风雨之夜」+ 第一部「晨曦之印」+ 第二部「星辰之印」+ 第三部「海洋之印 · 潮歌湾」+ 第四部「丰收之印 · 金穗平原」+ 第五部「战争之印 · 战痕古战场」+ 第六部「暮钟之印 · 暮色修道院」+ 终部「深渊之印 · 影渊要塞」，全七章**完整收官**：共 **88 个地点**、28 种敌人、**10 条支线**、对质线索与谜题旁路多套，**15 种结局**可收集（8 种章节收尾 + 5 种终局）
- **时长**：单周目约 240~300 分钟（含支线与探索），支持多周目与结局收集

## 二、玩法（与旧版分支剧情的区别）

| 旧版（章节卡片式） | 现版（文字RPG） |
|---|---|
| 一屏一段剧情 + 选项卡片推进 | **世界地图**：地点之间用方位按钮自由来去（↑北 ↓南 ←西 →东 / 上楼下楼） |
| 每个选择都是一次性分支 | 地点可反复探索：NPC 交谈、调查、商店、休息随时可用 |
| 状态只显示在侧栏 | 顶栏常驻 **🎒背包 / ⚔技能 / 👤角色 / 🗺地图** 按钮（快捷键 B / K / C / M），随时打开 |
| 战斗内嵌在剧情页 | **遭遇战 v2**：战斗写入同一份冒险日志，敌方小队条与同伴状态条常驻指令栏上方；每回合先看敌人**意图**，再决定出手/防御/用药 |
| — | **同伴与成长**：同伴是独立战斗单位（态势 AI 协同作战）；升级时**自选强化**，构建自己的流派 |
| — | **时间系统**：8 刻 = 1 天（清晨 / 白昼 / 黄昏 / 夜晚），每移动一段路 +1 刻，休息睡到次日清晨，部分剧情会拨动时间。侧栏常驻时辰，入夜与天亮会在日志里提示 |

### 指令栏
- **去路（方位按钮）**：显示当前地点所有可走的出口；有条件的出口会 🔒 灰显并提示原因
- **此处可做**：环顾四周、与 NPC 交谈、调查、休息、剧情动作（随进度出现）
- 剧情事件进行时，指令栏会临时切换为事件选项（谜题、战斗、抉择）

### 探索系统
- **世界地图总览**：顶栏 🗺 地图（快捷键 **M**）随时打开「艾尔多兰行记图」——按章节/小节列出全部地点，走过的逐格点亮，没去过的以雾（？？？）遮蔽，并统计探索度
- **旅途随机事件**：在野外地点之间赶路时，可能遇上云游诗人、逃难的农户、赶路的商队、遗落的行囊、低飞的鸦群、路旁的石堆、受惊的驮马；第二部之后还会遇见唱潮谣的渔人，第三部之后是怀里揣着麦穗的稻草人——小额得失与见闻，有独立冷却，不会连着刷
- **昼夜间换防的野外**：荒野的游荡者按时辰换班——白天古道是狼群、鸦眠坡是雾鸦，入夜后换「没脸的」雾中魅影上场（深林/沼泽/料场的夜晚遭遇率也更高）；唯独鸦眠坡入夜反而安静——乌鸦全睡了，静得能听见雾走路的声音
- **酒馆传闻与委托板**：请酒客喝一碗（2金币）听一条传闻——传闻池随天数与剧情解锁，讲过的不再重复（灰岭黑鸦旅店的老歪、驿镇的疤脸汉子）；旅店墙上的**委托木板每天换新**：讨伐式按击杀计数（战斗胜利自动累计），采办式备齐货物即交，办妥领赏记声望，侧栏实时显示进度
- **隐藏角落**：古井、地窖、白花泉、荒石料场、鸦眠坡、伐木场、苔藓谷、湖心洲、地宫、钟塔残基、不冻泉、灯庭、废矿、沉船湾、潮汐洞窟、老磨坊……每个章节都藏着与主线若即若离的地点：有的给装备（伐木斧 / 咏祭礼剑 / 鲸骨长枪 / 潮珠），有的给线索与谜底（古祠碑文 → 圣殿大门古谚；素娥与唐九的口信 → 灯柱晶屑的藏处；磨盘刻痕 → 丰年祭坛农谚），有的只是给世界添一层厚度
- **可交谈的人物**：第一部就有赵老汉、守渡人吴钩、老石匠莫大、养蜂人纪老爹、渔童阿满、香客唐九、老香客素娥等十余位 NPC——他们的台词随剧情推进而变化（符文重燃后赵老汉看见金顶亮了，吴钩托你向"点灯的人"道谢），NPC 之间也互相记得彼此（莫大的石屑要捎给索恩，阿满的烤鱼连着湖底的账）
- **支线与传闻联动**：下城区的施舍会印证渡鸦的传闻；卫戍营房的情报与溃兵营地的调令指向同一只手；老船长的潮汐口诀与守塔人的荧藻同指一扇海路——多走多问，戏就更足

### RPG 系统（战斗与角色 v2）
- **属性**：生命 HP、斗气✦ SP（主角每回合 +2，同伴 +1）、金币、声望、经验/等级、隐藏**侵蚀值**
- **装备**：三个装备位——**武器**（攻击加成，只加成物理技）、**防具**（受伤减免）、**饰品**（生命上限/斗气上限/会心率等）。行囊中点击「装备」穿上，角色面板可「卸下」
- **同伴系统**：艾莉娅/索恩/**卡雅**入队后是**独立战斗单位**，各有生命与斗气（随等级成长），按「态势」自动作战——**均衡**（残血时治疗/自保）/ **强攻**（全力输出）/ **守护**（优先格挡），战斗指令栏一键切换；生命归零会**昏厥**：可用药剂救醒，战后自动缓复两成，休息点全队恢复
- **升级自选强化**：每升 1 级四选一——生命+6 / 斗气+2 / 攻击+1 / 同袍协力（同伴上限成长）；主角 Lv4 解锁【回旋斩】（全体攻击）
- **技能表**：主角 ⚔挥剑 · 💥强袭斩 · 🌀回旋斩(Lv4) · 📢破胆吼（全体敌人伤害-2） · ☀️符文之刃 · 🌊潮汐之刃（海洋之印解锁） · 🌾穗浪千重（丰收之印解锁，全体） · 📯战号之锋（战争之印解锁） · 🔔暮钟长鸣（暮钟之印解锁，全体）；艾莉娅 ✨星火弹 · 🛡星辉庇护（全队减伤+驱毒） · 💚治愈星雨；索恩 🪓旋风斧 · 🛡铁壁 · 🔥战吼；卡雅 🔱迅叉连刺 · 🐋鲸涛斩 · 🌀潮环回斩（同伴技能由态势 AI 自动施展，敌众重击前会主动格挡）
- **战斗 v2**：每回合开头宣告敌人**意图**（⚠ 重击/淬毒/凝盾/锁链/雾遁/汲命……），可趁机**防御**（受伤大减+斗气+1）或调整目标；多敌人遭遇需选择攻击目标；潜行救援、飞扶壁攀爬、海滩合围等路线可获**先手**（首回合敌人措手不及）
- **敌人机制**：重击技（意图预告，可防）、淬毒、黑盾（先破盾再伤血）、星穹锁链（概率眩晕）、雾遁（物理无效，魔法仍可命中）、**汲命**（吸血回复）、敌众士气、BOSS 半血狂怒、护甲（物理减伤，魔法无视）、物理暴击；敌人也会**转火同伴**（同伴自带基础护甲）
- **侵蚀机制**：每点侵蚀使攻击 +1（深渊之力），但每场战斗开始时失去等量生命——力量与代价并存，且决定每一部的收尾走向
- **物品**：生命药水（回复10）/ 大生命药水（回复25），行囊与战斗中均可使用，会**自动救醒昏厥的同伴**；星光护符（濒死自动碎裂）；符文与关键道具（行囊中查看）
- **游荡遭遇**：雾林小径、山麓岔路、城西小巷、礁滩、田垄等地行走时可能遭遇敌人（有冷却，不会连着刷）；荒野路段则有更轻的**旅途事件**（见「探索系统」）
- **休息点**：旅店客房、黄昏营地、海底神殿咏泉、影渊谷口岩檐、要塞内庭（免费）；采药人小屋（3金币）；驿镇客栈（5金币）；穗安村（5金币）；渔家客栈（6金币）；界碑驿棚（4金币）；修道院静室（3金币）——**全队**生命斗气全满

### 小节与线索系统
- 每个地点带**小节标签**，章节/小节切换时在冒险日志中打印分隔行，顶栏章节显示「终部 · 深渊之印 · 终章 · 王座与黎明」
- **对质线索**：溃兵营地的调令线索（`deserterClue`）与藏书阁的先王家徽记载（`libClue`）会让「当庭揭发」一场戏多出整整两段台词——线索越多，揭发越有力（奖励相同，剧情演出不同）。卫戍营房与下城区也能补上旁证（营房情报可独立获得调令线索）
- **谜题提示的旁路**：圣殿大门的古谚，除了渡鸦的传闻与大殿经卷架，还能从**林中古祠的碑文**自己悟出来；丰年祭坛的五谷次序，蓉婆婆的农谚是正解，老磨坊被凿断的刻痕是旁证；战旗台的五旗次序，碑林将军碑文是正解，影蚀辎重营的**布阵图残页**（缺两面）是旁证；钟楼的三口钟次序，圣咏书朱批是正解
- **潮汐三件套**：老船长的口诀（或码头木牌）→ 守塔人的荧藻 → 大退潮之夜的海路——三步环环相扣，跳步会被🔒挡回
- **终局的三把钥匙**：① 安瑟姆的**遗嘱课**（`lore`）解锁王座前的「遗嘱」对话——莫格拉斯会失神，终战获得**先手**；② 谷口托渡鸦**送信白石城**（`alliance`），援军佯攻牵制，终战同样**先手**；③ 王座之战生命濒危时，可选择**以命铸封印**（晨曦之殉）。三条路通向同一座王座，五种结局等你裁定
- **剧情道具**：影蚀手记（圣殿回廊）、机关图志残页（藏书阁，星塔谜题免伤直解）、影蚀潮令（海底神殿，影蚀的下一步）、祭典谷种（老磨坊）、深渊螺壳（祭坛抉择，收下即染侵蚀）、**影蚀工令**（影蚀辎重营——他们在古战场挖的不是印，是通往影渊的地底暗渠）
- **探索装备**：咏祭礼剑（武器 攻击+2）、雾泽明珠（饰品 生命上限+3）、**伐木斧**（武器 攻击+2 · 湮没的伐木场）、**苇编哨**（饰品 斗气上限+3 · 湖底的船钱支线）、鲸骨长枪（武器 攻击+3 · 沉船湾沉箱）、潮珠（饰品 斗气上限+4 · 潮汐洞窟）、深海珍珠（饰品 生命上限+5 · 荧藻报酬）、**折戟长戈**（武器 攻击+4 · 军牌支线）、**战殁重铠**（防具 受伤-4 · 战将掉落）、**玉磬坠**（饰品 斗气上限+6 · 钟舌支线）——不进商店，只留给肯绕路的人
